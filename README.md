# Cloud-CICD-Project

Мой учебный сайт-портфолио на HTML, CSS и JavaScript.

На сайте есть разделы «Обо мне», «Навыки», «Проекты» и кнопка со случайным советом.

Файл `.github/workflows/deploy.yml` проверяет проект и публикует его на GitHub Pages при отправке изменений в ветку main.

Чтобы включить публикацию, в GitHub откройте Settings → Pages и выберите GitHub Actions.
